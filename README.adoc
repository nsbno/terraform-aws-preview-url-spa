= Terraform AWS Preview URL SPA

:!toc-title:
:!toc-placement:
:toc:


Infrastructure to generate preview URLs for Single-Page Applications (SPAs).
Designed to work with link:https://github.com/nsbno/terraform-aws-multi-domain-static-site[`nsbno/terraform-aws-multi-domain-static-site`].

== Usage

Remember to check out the link:variables.tf[*variables*] and link:outputs.tf[*outputs*] to see all options.

[source, hcl]
----
module "preview_url_spa" {
  source = "github.com/nsbno/terraform-aws-preview-url-spa?ref=x.y.z"

  providers = {
    aws.us_east_1 = aws.us_east_1
  }

  service_name = "infrademo-spa"
}
----

After creating the module, integrate it with your static site's CloudFront distribution using the `preview_url_module` parameter:

[source, hcl]
----
module "static_site" {
  source = "github.com/nsbno/terraform-aws-multi-domain-static-site?ref=3.0.0"

  # ... other configuration ...

  # Single line to enable preview URLs
  preview_url_module = module.preview_url_spa
}

# Add wildcard DNS record for PR subdomains
resource "aws_route53_record" "preview_wildcard" {
  zone_id = data.aws_route53_zone.main.zone_id
  name    = "*.test.example.com"
  type    = "A"

  alias {
    name                   = module.static_site.cloudfront_distribution_domain_name
    zone_id                = module.static_site.cloudfront_hosted_zone_id
    evaluate_target_health = false
  }
}
----
